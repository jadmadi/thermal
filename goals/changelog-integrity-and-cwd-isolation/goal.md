## Goal Description
Eliminate duplicate release sections, full-history `release-please` dumps, and leaked `(goals/<slug>/goal.md)` / `[goal: <slug>]` tokens from `CHANGELOG.md` and `internal/changelog/CHANGELOG.md`. Harden `internal/changelog` so `LoadContent()` always returns the compile-time embedded changelog instead of reading arbitrary `CHANGELOG.md` files from the user's current working directory, `Parse()` strips any Sila goal tokens and deduplicates release headers, and `scripts/simulated_user_gate.sh` enforces parity and token-free hygiene between root `CHANGELOG.md` and `internal/changelog/CHANGELOG.md`.

## Requirements
1. **Clean & Synchronize `CHANGELOG.md` and `internal/changelog/CHANGELOG.md`**:
   - Remove the duplicate `## [0.21.0]` full-history dump generated by `release-please` when `v0.20.1` had no git tag.
   - Strip all `(goals/<slug>/goal.md)` and `[goal: <slug>]` tokens across all historical entries in `CHANGELOG.md`.
   - Synchronize `internal/changelog/CHANGELOG.md` so both files match byte-for-byte.
2. **Isolate `LoadContent()` & Harden `Parse()` (`internal/changelog/changelog.go`)**:
   - Change `LoadContent()` to return `embeddedChangelog` directly instead of probing `CHANGELOG.md`, `../CHANGELOG.md`, and `../../CHANGELOG.md` in the current working directory.
   - Add `goalTokenRegex` in `Parse()` to strip `(goals/<slug>/goal.md)` and `[goal: <slug>]` references from bullet strings.
   - Deduplicate release version headers in `Parse()` so a repeated `## [x.y.z]` section never produces duplicate release cards.
3. **Simulated User Gate Enforcement (`scripts/simulated_user_gate.sh`)**:
   - In Section 13 (`Release Communication & Changelog Integrity Checks`), assert that `CHANGELOG.md` and `internal/changelog/CHANGELOG.md` are identical, contain zero `(goals/` or `[goal:` substrings, and contain no duplicate `## [x.y.z]` version headers.
